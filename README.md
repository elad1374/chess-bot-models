# Chess Bot Trained Models & Weights

This repository contains the pre-trained weights and models for the **Chess-Bot** project.  

---

## Setup & Installation

To run the main chess robot application, you must download the models from this repository and place them in the correct directory of the main project.

### 1. Clone this Repository
Download or clone this repository to your local machine:
```bash
git clone [https://github.com/elad1374/chess-bot-models.git](https://github.com/elad1374/chess-bot-models.git)
```
Afterwords copy it into the chess-bot/runs folder
